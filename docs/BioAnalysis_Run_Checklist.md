# BioAnalysis Run Checklist

Use this checklist as the execution gate for a genome project. Every stage should produce traceable outputs before the next stage begins.

Examples use anonymized placeholders such as `Arabidopsis_thaliana`, `Arabidopsis_lyrata`, and `Arabidopsis_halleri`.

```text
Input -> Command/script -> Expected output -> QC pass criteria -> Next input
```

## Stage checklist

| Stage | Input | Command/script | Expected output | QC pass criteria | Stop conditions |
|---|---|---|---|---|---|
| 01 Preprocessing and contamination screening | Raw reads or assembly FASTA, local NT resources when available | `scripts/01_preprocessing/01_nt_decontaminate_contigs.sh`, file inventory checks | File manifest, length/N50 reports, optional NT-filtered FASTA | Inputs exist, IDs are unique, contamination decisions are documented | Missing input files, undocumented database versions, or ambiguous sample IDs |
| 02 Independent genome survey, ploidy estimation, assembly, Hi-C scaffolding, statistics, and QC assessments | Short-read genome survey reads, WGS sorted BAM for ploidyNGS, HiFi/ONT/PacBio/Illumina assembly reads, optional Hi-C reads, filtered assembly FASTA, optional read FASTQ/FASTA for QV | `scripts/02_assembly/run_genome_survey_workflow.sh`, `run_ploidyngs_workflow.sh`, `run_hifiasm_assembly.sh`, `run_nextdenovo_assembly.sh`, `run_spades_assembly.sh`, `run_flye_assembly.sh`, `run_canu_assembly.sh`, `run_verkko_assembly.sh`, `run_yahs_scaffolding.sh`, `run_haphic_scaffolding.sh`, `assembly_stats.py`, BUSCO/LAI/Merqury workflows | GenomeScope/Smudgeplot genome survey outputs, k-mer histogram, ploidyNGS table/PDF, assembly FASTA, scaffold FASTA/AGP, assembly/scaffold stats, BUSCO summary, LAI summary, Merqury QV summary, retained logs | FASTA/read/BAM inputs are non-empty, sequence IDs are unique where FASTA is produced, genome survey and ploidy estimates are plausible; read technology, k-mer/ploidy/hash-size choices, genome-size estimates, Hi-C pair definitions, BUSCO lineage, LAI thresholds, Merqury k-mer/read inputs, and tool/database versions are documented | Empty reads, BAM, or assembly, duplicate IDs, implausible genome survey or ploidy estimates, unresolved assembler/scaffolder failure, missing paired reads, unsupported read type, missing expected final FASTA/AGP, missing BUSCO lineage, missing LAI output, missing read evidence for Merqury QV, undocumented database versions |
| 03 Repeat annotation and TE/EVE post-processing | Genome FASTA, repeat tools, optional TEsorter domains, RepeatMasker `.out`, EVE/GEVE calls, target/background BED | `scripts/03_repeat/run_repeat_annotation_workflow.sh`, `scripts/03_repeat/run_te_eve_postprocessing_workflow.sh`, plus Stage 03 helper scripts | Uppercase genome, repeat libraries, RepeatMasker GFF3/summary, TRF outputs, standardized EVE/GEVE BED/TSV, TEsorter domain summaries, divergence summaries | LTR and RepeatModeler outputs are non-empty when expected; repeat and target/background coordinates are valid; external caller/database provenance is documented | Missing `.scn`, missing library, unmerged RepeatMasker outputs, invalid BED coordinates, undocumented EVE/GEVE or TEsorter source |
| 04 GFF/CDS/PEP extraction and structure statistics | Genome FASTA, gene annotation GFF/GTF, manifest, optional comparison-species GFFs | `scripts/04_gff/gff_cds_pep.py`, `scripts/04_gff/run_gff_structure_workflow.sh` | Clean GFF, CDS, protein FASTA, CDS check tables, GFF structure metrics, distributions, chromosome summaries, QC tables, plot handoff tables, optional R PDFs | IDs match genome/GFF, no retained internal-stop CDS unless justified, duplicate IDs and Parent links are checked, coordinates are in bounds when genome FASTA is supplied | Missing seqids, widespread CDS errors, ID convention conflicts, duplicate feature IDs, missing Parent references, out-of-bound coordinates |
| 05 Genome features, introns, region context, and methylation | GFF3, genome FASTA, target/background BED, optional Bismark CX report, optional Introner-elements tools | `scripts/05_genome_features/run_genome_features_workflow.sh`, `scripts/05_genome_features/run_region_context_workflow.sh`, plus Stage 05 helper scripts | Intron BED, unique intron BED, short intron BED, AT-rich summaries, feature enrichment tables, methylation bin/context summaries, introner candidate outputs | BED coordinates are 0-based half-open; target/background definitions are comparable; Bismark coverage thresholds are documented; unique loci are used for density; external tool paths are documented outside the repo | Coordinate-system conflict, missing genome FASTA for AT metrics, unverified introner outputs, low CX coverage, incomparable target/background regions |
| 06 Functional annotation, COG/NOG summaries, and GO handoffs | Protein FASTA, clean GFF, CDS QC, database outputs, optional term maps and foreground sets | InterProScan, eggNOG, KofamScan, DIAMOND/BLASTP, `scripts/06_annotation/run_functional_annotation_workflow.sh`, `scripts/06_annotation/run_go_enrichment_plot_handoff.sh`, plus Stage 06 helper scripts | Parsed annotation tables, `functional_annotation.tsv`, GO/KEGG/Pfam/domain summaries, COG/NOG category summaries, optional enrichment and semantic-plot handoff tables | Query IDs match protein FASTA; missing annotations are recorded as `NA`; term maps, eggNOG database versions, foreground/background IDs, and external plotting tools are documented | ID mismatch, missing database output, empty merged table, undocumented term-map source, ambiguous eggNOG category columns, untraceable GO plot input |
| 07 Gene families, target-family discovery, expression evidence, and phylogeny helpers | Protein FASTA per species, species list, selected genes/families, functional annotation, target rule tables, optional expression matrix | OrthoFinder, MAFFT, trimAl, IQ-TREE/RAxML, RSEM/TPM matrices, `scripts/07_gene_family/run_gene_family_workflow.sh`, `scripts/07_gene_family/run_target_family_workflow.sh`, plus Stage 07 helper scripts | Prefixed FASTA files, OrthoFinder orthogroups, family summaries, selected member lists, target-family evidence tables, peptide FASTA handoffs, expression summaries, alignments, trees, tip annotations | Species names match across FASTA, count matrix, and trees; orthogroup member IDs are traceable; target-family rule provenance is documented; expression IDs match selected genes; failed families are logged | Species-name mismatch, empty orthogroups, empty target gene set, missing rule provenance, expression ID mismatch, empty alignments, untracked failed trees |
| 08 Gene-family evolution with Count, CAFE, and target-family integration | OrthoFinder gene-count table, family summary, species tree, optional target-family evidence | Count, CAFE/CAFE5, `scripts/08_gene_family_evolution/run_gene_family_evolution_workflow.sh` plus Stage 08 helper scripts | Count input, parsed gain/loss table, family/node gain-loss summaries, CAFE input, filtered families, removed-family table, target-family evolution summaries, CAFE results | Tree tips match count-matrix columns; rejected or removed families have reasons; target-family genes map to orthogroups; ultrametric-tree and model assumptions are documented | Tree/count mismatch, unsupported Count output format, undocumented ultrametric tree, missing removed-family reasons, target-family genes lacking orthogroup mapping |
| 09 Synteny context, MCScan/JCVI summaries, heatmaps, and Circos links | Genome FASTA, GFF3, protein FASTA, gene BED, target/background BED, anchor/block files | minimap2, WGDI/MCScanX/JCVI, `scripts/09_synteny/run_synteny_context_workflow.sh`, `scripts/09_synteny/anchors_to_circos_links.py` | Dotplots, normalized synteny tables, pairwise heatmap matrices, region synteny summaries, Circos links | Chromosome IDs match; link coordinates are in bounds; MCScan/JCVI input format is documented; target/background coordinate systems match | Out-of-bound coordinates, missing chromosome IDs, unsupported anchor format, untraceable region definitions |
| 10 HGT screening, validation, and family integration handoff | Query FASTA, NR BLAST/DIAMOND hits or taxon-group NR databases, blast2hgt taxonomy database, GFF, intron/synteny evidence, optional donor taxonomy, orthogroups, target-family evidence, family-evolution results | `scripts/10_hgt/run_hgt_blast2hgt_workflow.sh`, `scripts/10_hgt/run_hgt_family_integration_workflow.sh`, plus Stage 10 helper scripts | Blast2hgt lineage table, HGT candidate scores, context table, validation ID lists, refined donor summaries, HGT-family evolution support tables | Candidate calls distinguish `candidate`, `rejected`, `unknown`, `missing`, and `not_tested`; blast2hgt database provenance is documented; donor-taxonomy provenance is recorded; no remote data access is hidden | Missing taxonomy mapping, insufficient donor signal, missing blast2hgt database setup, candidate on suspicious contaminant scaffold, untraceable donor taxonomy, missing orthogroup/evolution links |
| 11 Visualization matrices and final deliverables | QC summaries, analysis tables, gene sets, expression/evolution/HGT integration tables | `scripts/11_visualization/run_visualization_handoff_workflow.sh`, Circos, external plotting tools | Plot-ready matrices, matrix manifests, figures, evidence tables, reproducible methods notes | Every final claim maps back to a command, file, and matrix manifest row; plotting dependencies are documented | Untraceable figure/table values, missing provenance, matrix source mismatch |

## Continuous extension checklist

When adding another workflow:

1. Add scripts under the appropriate numbered stage.
2. Add command examples.
3. Add SOP/checklist entries.
4. Add script provenance and status.
5. Keep examples anonymized.
6. Keep repository text in English.
7. Run `make check-all` before commit.
